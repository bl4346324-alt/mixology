# 微醺工坊 (MixoCraft) - 鸡尾酒调酒小程序与跨端应用

> **“在家调一杯好酒”** —— 专为年轻人打造的居家调酒、智能酒柜逆向匹配、AI 灵感侍酒与派对点单小程序。基于 Vue 3 + TypeScript + Vite + Uni-app 现代化跨端架构构建，一套代码可直接输出**微信小程序**与 **iOS / Android 原生 App**。

---

## 🌟 核心特色与功能

1. **智能酒柜与逆向匹配引擎（超越 Bar-Assistant）**
   * **打卡我的酒水库存**：支持按烈酒、利口酒、苏打与茶饮、果汁鲜果、糖浆分级打卡，支持“仅看便利店易购”极速勾选。
   * **今晚可做 (100% 满足)**：自动匹算并展示家中原料完全具备的鸡尾酒单。
   * **平替可做**：支持智能原料平替（如青柠汁平替黄柠檬汁、波旁平替通用威士忌）。
   * **差 1 种原料**：清晰提示缺失的原料，并标注便利店是否容易购买。
   * **采购投资回报榜（Mixel 式贪心算法）**：自动计算“买哪一瓶原料能解锁最多的新酒单”，指引最高性价比的添酒方案！

2. **精选本土化与全景酒谱库**
   * **IBA 经典官方鸡尾酒**：莫吉托、金汤力、古典鸡尾酒、玛格丽特、内格罗尼、大都会、威士忌酸、莫斯科骡子等。
   * **便利店与超市神仙特调**：三得利乌龙威士忌茶嗨棒、东方树叶茉莉金汤力、养乐多真露微醺、野格红牛炸弹等。
   * **新中式茶酒**：炭焙乌龙威士忌酸等中式茶香探索。
   * **零酒精特调 (Mocktails)**：无酒精莫吉托等全年龄/驾驶员友好饮品。

3. **沉浸式调酒工作台 (Bartending Canvas)**
   * **全屏大字模式**：远距离清晰可见，操作间距大，湿手盲操无压力。
   * **实时单位与人份换算**：一键切换 1/2/4 人份，毫升 (ml)、美制盎司 (oz)、矿泉水瓶盖 (约5ml)、汤勺 (约15ml) 实时换算。
   * **摇酒节拍器 (Shake Metronome)**：12 秒摇酒节拍光晕脉动与轻震动提示。
   * **搅拌计时器 (Stir Timer)**：30 秒顺滑搅拌倒计时与 20% 融水率科学提示。
   * **微醺打卡手记**：制作完成打星评价与记录感言。

4. **AI 微醺侍酒师 (AI Mixologist)**
   * 根据当前心境（放松、派对、治愈、浪漫）、期望酒精度（0% / 微醺 / 经典 / 烈酒）与现有食材，智能推演风味平衡。
   * 生成专属特调故事、配方比例与五维风味平衡雷达图（甜、酸、烈、苦、清爽）。

5. **社交裂变神器：派对吧台模式 (Party Bar Mode) & 微醺海报**
   * **派对吧台点单**：房主一键开启“今晚营业”，朋友微信扫码进入专属今日酒单点单，房主实时收到出酒通知与订单队列！
   * **拍立得微醺海报**：一键生成高颜值酒单卡片，支持直接保存到手机相册分享至小红书与朋友圈。

## 📱 真机（苹果 iPhone / 安卓 Android）测试指南

### 方式一：微信开发者工具扫码真机测试（最推荐，体验与真机小程序一致）

1. **下载并打开微信开发者工具**（[官网免费下载](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)）。
2. 在开发者工具中点击 **“导入项目”**：
   * **项目目录**：选择本项目下的 `dist/build/mp-weixin` 目录；
   * **AppID**：可选择 **“测试号”**（默认已配置 touristappid），或填入您在 [微信公众平台](https://mp.weixin.qq.com/) 免费注册的个人小程序 AppID；
3. 导入后即可在电脑模拟器中预览操作。
4. **真机测试**：
   * 点击顶部工具栏的 **「预览」** 按钮；
   * 屏幕会弹出一个二维码，**用任何苹果（iPhone）或安卓（Android）手机的微信扫一扫**，即可立刻在手机真机上全屏运行体验！
   * 若需排查特定设备问题，可点击 **「真机调试」** 按钮进行远程联调。

### 方式二：浏览器 / 手机 H5 快速预览

本项目基于 Uni-app，同时支持 H5 模式：
```bash
# 启动 H5 开发热重载服务器
npm run dev:h5
```
启动后终端会输出本地访问链接（如 `http://localhost:5173` 或局域网 IP 如 `http://192.168.x.x:5173`），手机与电脑连同一个 WiFi 时，手机浏览器打开该 IP 即可直接测试。
